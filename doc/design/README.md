# PyMApp PLAT - Java SE

Implementación de la capa de plataforma de PyMApp Framework para Java Standard Edition.

## Funcionalidades

- Configuración.
- Logging.
- Gestión del ciclo de vida del módulo.

## Componentes principales

- PyMApp_plat_jse
- ConfigPLAT
- LogPLAT
- I18n del módulo (`i18n/text/Text_*.java`)

## Documentación

- **design/01_architecture/** — arquitectura, abstracción de plataforma, ciclo de vida, formatos de recursos y configuración del módulo.
- **design/02_adr/** — registros de decisiones de arquitectura (ADR).
- **design/03_diagrams/** — diagramas PlantUML (vista principal, componentes, estados, secuencia de inicio y mapa de dependencias).
